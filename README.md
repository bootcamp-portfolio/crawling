# Web Crawling Study

웹 크롤링과 웹 데이터 수집 학습을 위한 노트북 및 예제 자료 저장소입니다.

## 학습 주제
- 크롤링과 스크래핑 기초
- Beautiful Soup
- Selenium
- 웹 API 활용
- 강의 정보 수집 실습

## 구성
- `note/`: 주제별 Jupyter Notebook 및 수업 노트
- `data/`: 실습에 사용된 이미지와 예제 데이터

## 사용 방법
Python 환경에서 Jupyter Notebook을 실행하고 각 노트북을 순서대로 확인하세요. Selenium 실습은 브라우저 및 드라이버 설정이 추가로 필요할 수 있습니다.

> 실습 대상 웹사이트의 이용약관과 robots 정책, 관련 법령을 확인한 뒤 데이터를 수집하세요.
